# Random Password Generator

Имя и фамилия автора: Махмудов Мурад Максимович
Название проекта: Random Password Generator (Генератор случайных паролей)
Язык: Python 3.x

Описание проекта
Это графическое приложение (GUI), предназначенное для генерации случайных паролей с заданными параметрами. Пользователь может настроить длину пароля и выбрать типы используемых символов (цифры, буквы, спецсимволы).

Приложение сохраняет историю сгенерированных паролей в файл password_history.json и автоматически загружает её при запуске.

Технологии и библиотеки
Python: Язык программирования.
Tkinter: Стандартная библиотека Python для создания графического интерфейса.
random: Стандартная библиотека для генерации случайных чисел и последовательностей.
json: Стандартная библиотека для работы с форматом JSON.
string: Стандартная библиотека для получения наборов символов (цифры, буквы).
Git: Система контроля версий.

Инструкция по запуску
1. Убедитесь, что у вас установлен Python версии 3.6 или выше.
2. Скачайте или клонируйте репозиторий на свой компьютер.
3. Откройте терминал (командную строку) в папке с проектом.
4. Запустите приложение командой:
python main.py

Использование приложения
1. Настройка длины: Используйте ползунок «Длина», чтобы установить количество символов в пароле (от 4 до 32).
2. Выбор символов: Отметьте галочками чекбоксы «Цифры», «Буквы» и/или «Спецсимволы». Необходимо выбрать хотя бы один вариант.
3. Генерация: Нажмите кнопку «Сгенерировать пароль».
4. Результат: Сгенерированный пароль появится в поле ввода над кнопкой.
5. История: Все созданные пароли отображаются в таблице «История» в нижней части окна. История сохраняется между запусками программы.

Примеры использования (Тестирование)

Позитивный сценарий:
Установить длину 8.
Выбрать «Цифры» и «Буквы».
Нажать «Сгенерировать».
Ожидаемый результат: В поле появится пароль из 8 символов (например: a7B2c9D1). Запись добавится в историю.

Негативный сценарий (Ошибка валидации):
Снять все галочки с типов символов.
Нажать «Сгенерировать».
Ожидаемый результат: Появится окно с ошибкой «Выберите хотя бы один тип символов».

Граничный случай:
Установить минимальную длину (4).
Выбрать только «Спецсимволы».
Нажать «Сгенерировать».
Ожидаемый результат: Сгенерируется пароль из 4 спецсимволов (например: !@#$).
