# Random Quote Generator — генератор случайных цитат

Автор:Ханилаев Абубакр Ханилавович
Дата: 01.05.2026

## Описание проекта

Random Quote Generator — это графическое приложение на Python для генерации случайных цитат из предопределённого списка. Программа сохраняет историю сгенерированных цитат с временной меткой и позволяет фильтровать их по автору и теме.

## Возможности

- Генерация случайной цитаты по нажатию кнопки.
- Отображение автора и темы цитаты.
- История сгенерированных цитат с датой.
- Фильтрация по автору и теме.
- Автоматическое сохранение и загрузка данных из `quotes_data.json`.
- Интуитивно понятный интерфейс на Tkinter.

## Требования

- Python 3.7+
- Библиотека Tkinder (входит в стандартную поставку Python).

## Инструкция по запуску

1. Убедись, что установлен Python 3.7 или новее.
2. Склонируй репозиторий:
   ```bash
   git clone https://github.com/[твой_логин]/random-quote-generator.git
   cd random-quote-generator
   ```
3. Запусти приложение:
   ```bash
   python main.py
   ```
4. Для работы с Git используй стандартные команды (`git add .`, `git commit -m "..."`, `git push`).

## Примеры использования

- **Сгенерировать цитату:** нажми кнопку — появится случайная цитата.
- **Фильтровать:** выбери автора или тему и нажми «Применить фильтр».
- **История:** последние 20 цитат отображаются в списке.
- **Сохранить историю:** данные сохраняются автоматически при генерации или фильтрации.
