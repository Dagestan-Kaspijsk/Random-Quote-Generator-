Описание программы
«Random Quote Generator» — это графическое приложение для генерации случайных цитат из предопределённого списка. Программа отображает текст цитаты, автора и тему, сохраняет историю сгенерированных цитат в файл и позволяет фильтровать историю по автору или теме. Данные хранятся в формате JSON.

Требования для запуска
Python 3.10 или выше.
Библиотеки:
pip install PyQt6

Как запустить

1. Клонируйте репозиторий:
git clone https://github.com/твой-логин/random-quote-generator.git
cd random-quote-generator

2. Установите зависимости:
pip install -r requirements.txt

3. Запустите приложение:
python main.py

Как пользоваться программой
Нажмите кнопку «Сгенерировать цитату» — в окне появится случайная цитата с указанием автора и темы.
История всех сгенерированных цитат отображается в списке ниже.
Для фильтрации истории выберите автора и/или тему из выпадающих списков и нажмите «Фильтровать историю».
Все данные (основной список и история) сохраняются в JSON-файлы.
Новые цитаты можно добавить вручную в файл quotes.json.

Пример работы программы
Генерация:
Нажать «Сгенерировать цитату».
Пример вывода: «Успех — это умение двигаться от неудачи к неудаче, не теряя энтузиазма». — Уинстон Черчилль (Мотивация)Фильтрация:
Выбрать автора: «Уинстон Черчилль».
Нажать «Фильтровать историю» — отобразятся только цитаты этого автора.Добавление новой цитаты:
Открыть quotes.json.
Добавить объект: {"text": "...", "author": "...", "topic": "..."}
Перезапустить программу.
