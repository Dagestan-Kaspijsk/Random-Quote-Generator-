Random Quote Generator — Генератор случайных цитат
Автор: Алибекова Мариям Низамиевна
Вариант: Random Quote Generator (Генератор случайных цитат)
Дата сдачи: 30.04.2026

«Random Quote Generator» — это графическое приложение для генерации случайных цитат из предопределённого списка. Программа отображает текст цитаты, автора и тему, сохраняет историю сгенерированных цитат в файл и позволяет фильтровать историю по автору или теме. Данные хранятся в формате JSON. При запуске программа автоматически восстанавливает историю из файла.

Требования для запуска
Python 3.10 или выше.
Библиотеки:
pip install PyQt6

Как запустить

1. Клонируйте репозиторий:
git clone https://github.com/твой-логин/random-quote-generator.git
cd random-quote-generator

2. Установите зависимости:
pip install -r requirements.txt

3. Запустите приложение:
python main.py

4. Для добавления новых цитат откройте файл quotes.json и добавьте объект в формате:
{
  "text": "...",
  "author": "...",
  "topic": "..."
}

5. Перезапустите программу.

Как пользоваться программой
1. Нажмите кнопку «Сгенерировать цитату» — в окне появится случайная цитата с указанием автора и темы.
2. История всех сгенерированных цитат отображается в списке ниже.
3. Для фильтрации истории выберите автора и/или тему из выпадающих списков и нажмите «Фильтровать историю».
4. Все данные (основной список и история) сохраняются в JSON-файлы.
5. При повторном запуске история будет восстановлена из файла history.json.
6. Программа проверяет корректность структуры загружаемых JSON и сообщает об ошибках.

Пример работы программы
Генерация:
Нажать «Сгенерировать цитату».
Пример вывода: «Успех — это умение двигаться от неудачи к неудаче, не теряя энтузиазма». — Уинстон Черчилль (Мотивация)Фильтрация:
Выбрать автора: «Уинстон Черчилль».
Нажать «Фильтровать историю» — отобразятся только цитаты этого автора.Добавление новой цитаты:
Открыть quotes.json.
Добавить объект: {"text": "...", "author": "...", "topic": "..."}
Перезапустить программу.Восстановление истории:
После закрытия и повторного запуска приложения история будет загружена из файла.Обработка ошибок:
Если quotes.json повреждён или имеет неверную структуру, появится предупреждение, и программа продолжит работу с пустым списком.
